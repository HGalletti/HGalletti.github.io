## Selected Projects

### [Forecasting Interest Rate Spreads](https://github.com/HGalletti/Forecasting-Spread-Treasury-Bonds.git)

**Graduate project — M.Sc. in Data Science**

A time-series forecasting study focused on the 2Y–10Y U.S. Treasury spread. The project compares classical statistical models including ARIMA, SARIMA, and SARIMAX, incorporating market variables such as the VIX and S&P 500 as exogenous predictors.

The analysis includes stationarity testing, transformations, model selection, train-test evaluation, and residual diagnostics.

### [CV Assistant Chatbot](https://huggingface.co/spaces/HernanGalletti/CV_Hernan_Galletti)

Personal project implementing a Retrieval-Augmented Generation (RAG) application to answer questions about my professional experience, education, and skills.

Built with LangChain, ChromaDB, and Gradio, with bilingual support in English and Spanish and retrieval over embedded profile documents.

The project is no longer actively maintained and the hosted demo may currently be unavailable.

### [Electoral Assistant](https://github.com/HGalletti/Asistente_electoral)

**Graduate project — M.Sc. in Data Science**

A Retrieval-Augmented Generation (RAG) application designed to answer legal and operational questions about the 2025 Buenos Aires City elections using official electoral documents and regulations.

The system uses LangChain, OpenAI language models, embeddings, and a Chroma vector database to retrieve relevant source material and generate grounded responses.
